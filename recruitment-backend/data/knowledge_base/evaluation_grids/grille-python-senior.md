# Grille d'évaluation — Développeur Python Senior

## Barème global (0–10)

| Critère | Poids | Seuil minimum | Excellent (9–10) |
|---------|-------|---------------|---------------------|
| Maîtrise Python & écosystème | 30 % | 6 | Patterns avancés, perf, async maîtrisé |
| Conception API & architecture | 25 % | 6 | APIs versionnées, résilience, idempotence |
| Qualité & tests | 20 % | 6 | Stratégie de tests claire, TDD partiel |
| Collaboration & communication | 15 % | 5 | Exemples concrets de revues et doc |
| Adéquation poste / motivation | 10 % | 5 | Alignement stack et culture produit |

## Recommandation RH

- **Recruter (HIRE)** : score pondéré ≥ 7,5 et aucun critère obligatoire < 6
- **Liste d'attente (WAITLIST)** : score 6,0–7,4 ou un critère technique à 5–6 avec potentiel
- **Rejeter (REJECT)** : score < 6 ou réponses factuellement incorrectes sur le cœur Python

## Questions techniques types

1. Différence entre asyncio et threading pour I/O bound
2. Design d'un endpoint idempotent avec gestion de conflits
3. Stratégie de migration de schéma PostgreSQL sans downtime

## Red flags

- Incapacité à expliquer un projet personnel ou pro récent
- Score technique < 4 malgré CV sur-qualifié
- Refus de parler des tests ou de la dette technique
